Webdesign

Portfolio

Voor mijn opleiding heb ik als eerste web project een portfolio opdracht gekregen. Doorheen het jaar maakten we kennis HTML-structuur en werking, leerde we werken met Bootstrap om onze website te stylen en kregen we een voorproefje Javascript en API's. Door aan deze site te werken en mijn ideeën vanop papier om te zetten naar zijn digitale variant, heb ik veel geleerd. Gaande weg moet je op zoek gaan, code vergelijken en via tutorials of video's een oplossing zoeken dat werkt voor jouw website.

Elke keer als je aan de site werkt ontdek je iets nieuw. En je groeit doorheen de opdracht waardoor je ook steeds terugkeert naar jouw oudere code die je hebt geschreven en verbeter je die indien nodig. Dat is ook iets wat ik zeker wil blijven doen ook na deze opdracht. Ik heb nog een paar ideeën die ik graag zou implementeren in de toekomst.
